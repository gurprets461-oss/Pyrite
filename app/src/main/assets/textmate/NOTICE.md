# Third-party TextMate assets

Copied from the sora-editor demo app (https://github.com/Rosemoe/sora-editor,
`app/src/main/assets/textmate/`, commit 94681e9e).

- `python/syntaxes/python.tmLanguage.json`: MagicPython grammar as shipped by VS Code
  (https://github.com/microsoft/vscode/tree/main/extensions/python), MIT License,
  Copyright (c) 2015-present MagicStack Inc. and Microsoft Corporation.
- `python/language-configuration.json`: from VS Code's Python extension (MIT); Pyrite
  adds `match`/`case`/`lambda` to the indent-on-Enter rule.
- `quietlight.json`: VS Code "Quiet Light" theme (MIT, Microsoft Corporation).
- `darcula.json`: Darcula-style theme from the sora-editor demo (LGPL-2.1, like sora-editor).
